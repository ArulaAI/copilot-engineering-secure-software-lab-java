# Lean workflow rehearsal

Record the exact source state and approved IDE/plugin/model once for the rehearsal. Measure actual
elapsed time; do not assume instruction simplification proves a speed or usage gain.

- Mapper works directly and includes configuration.
- Discovery covers standalone components and separates defects, reachability and verification.
- Modeling preserves scenario prerequisites, consistent traceability and five evidence-ranked priorities.
- Named implementation prompt leads to code/tests without a plan/ledger or repeated approval question.
- Create runs focused tests and regression, reports results, and stops without selecting another task.
- Fresh Critique independently tests, gives a concise verdict and writes one short review entry.
- Concrete correction returns to Create without counters, metadata repair or repeated successful runs.
- Old tasks.md/change-plan.md/task-reviews.md never trigger validation or repairs.
- Missing irrelevant earlier gates do not block the requested implementation/review.
- Unstarted priorities remain open without questions or formal deferral.
- Blocked integration is disclosed once, not retried through multiple harnesses.
- Final review closes out completed changes without new audits/tests, reuses matching current accepted evidence or runs one needed regression, and writes one short summary. Advanced topics stay verbal; handoff captures any state when requested.
